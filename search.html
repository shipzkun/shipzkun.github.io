Strings Index

Hi! You’re in the special search page. These all contain page content strings that satisfy the following pseudocode:

strings.split(/\p{Space}/).each do |word|
	if word =~ /\p{Hiragana}|\p{Katakana}|\p{Han}/ then
		add_to_corpus(get_jp_words(word))
	else
		word.sub!(/\A[\p{Pi}\p{Ps}\p{Po}]+/, '')
		word.sub!(/[\p{Pf}\p{Pe}\p{Po}]+\z/, '')

		if word =~ /[\p{Word}]+/ then
			add_to_corpus(word.downcase)
		end
end

To avoid unnecessary total count inflation for some words, the header and sidebar contents are not considered. TinySegmenter is used to extract the Japanese “words” properly.

This page is also excluded to avoid double-counting. As proof, this string should not appear below: ABCDEFGHIJKLMNÑNGOPQRSTUVWXYZ1234567890₱
